# 交通流量预测系统 - 启动说明

## 快速启动

### 方式1：直接运行（推荐）
在项目目录下打开命令行，执行：

```bash
python app.py
```

然后在浏览器中访问：http://127.0.0.1:8000

### 方式2：使用启动脚本
双击运行 `run_server.bat`

---

## 功能说明

### 1. 数据上传
- 支持CSV格式，包含三列：`timestamp`, `intersection_id`, `traffic_volume`
- 示例数据已生成在 `data/sample_traffic_data.csv`

### 2. 模型训练
如需训练新模型，执行：
```bash
# 生成示例数据并训练
python train_model.py --generate_sample --csv_path data/sample_traffic_data.csv

# 使用自定义参数训练
python train_model.py --hidden_size 128 --epochs 100 --learning_rate 0.0005
```

### 3. 超参数调优
```bash
python hyperparameter_tuning.py --intersection_id INT_001
```

## 常见问题

### Q: 浏览器无法访问页面？
A: 请检查：
1. 确认命令行中显示服务器已启动
2. 确认访问地址为 http://127.0.0.1:8000
3. 确认8000端口未被其他程序占用

### Q: 预测时间点无法选择？
A: 请先：
1. 上传CSV数据文件
2. 选择一个路口ID
3. 系统会自动加载可用的预测时间点

### Q: 如何使用自己的数据？
A: 确保CSV文件包含以下三列：
- `timestamp`: 时间戳 (格式: YYYY-MM-DD HH:MM:SS)
- `intersection_id`: 路口ID
- `traffic_volume`: 车流量数值

## API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/intersections` | GET | 获取已训练模型的路口列表 |
| `/api/upload` | POST | 上传CSV数据文件 |
| `/api/predict` | POST | 单小时预测 |
| `/api/predict_range` | POST | 多小时连续预测 |
| `/api/historical` | GET | 获取历史数据 |
| `/api/available_times` | GET | 获取可用预测时间点 |
| `/api/model_info` | GET | 获取模型信息 |
| `/api/data_status` | GET | 获取数据加载状态 |
