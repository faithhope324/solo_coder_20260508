# 3D 相册

一个基于 Three.js 的 3D 相册应用，多张图片排列成圆形墙，相机围绕中心旋转，支持点击查看详情。

## 功能特性

- 🌐 **3D 画廊布局**: 12张图片排列成圆形墙，环绕展示
- 🎥 **相机控制**: 自动旋转 + 手动拖拽旋转 + 滚轮缩放
- 👆 **点击交互**: 点击图片放大并切换到正面查看
- 🖼️ **模态框展示**: 背景变暗显示图片详情，支持左右箭头切换
- ✨ **过渡动画**: 平滑的位置、旋转、缩放过渡动画
- 📱 **响应式设计**: 支持桌面和移动端触摸操作

## 模块结构

```
js/
├── gallery.js      # 3D 画廊布局模块 - 负责纹理加载和图片布局
├── camera.js       # 相机控制器模块 - 控制相机旋转、缩放、聚焦
├── interaction.js  # 点击交互模块 - 处理鼠标/触摸事件
├── modal.js        # 模态框模块 - 图片详情展示和切换
└── main.js         # 主入口文件 - 初始化和整合所有模块
```

## 运行方式

由于使用了 ES 模块和外部图片资源，需要通过 HTTP 服务器运行：

### 方法 1: 使用 Python
```bash
python -m http.server 8000
```

### 方法 2: 使用 Node.js (http-server)
```bash
npx http-server -p 8000
```

### 方法 3: 使用 VS Code Live Server 插件

然后在浏览器中访问 `http://localhost:8000`

## 操作说明

- **拖拽**: 旋转视角
- **滚轮**: 缩放视图
- **点击图片**: 查看详情
- **ESC / 点击背景**: 关闭详情
- **← → 箭头 / 按钮**: 切换图片

## 技术栈

- Three.js r128 - 3D 渲染引擎
- 原生 JavaScript (ES6+)
- CSS3 动画和过渡
