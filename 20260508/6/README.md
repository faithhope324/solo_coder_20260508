# 二维拉普拉斯方程求解 - 平行板电容器

本项目实现了二维拉普拉斯方程的数值求解，用于模拟平行板电容器之间的电势分布。

## 项目结构

```
.
├── app.py          # Flask应用主文件
├── laplace_solver.py  # 独立的求解脚本
├── templates/      # 前端模板文件夹
│   └── index.html  # 前端界面
└── README.md       # 项目说明
```

## 核心功能

1. **有限差分法求解**：使用迭代法求解二维拉普拉斯方程
2. **电场计算**：从电势分布计算电场强度
3. **可视化**：生成电势等高线图和电场线（箭头表示）
4. **参数设置**：可设置板间距、上板电压和下板电压

## 技术实现

- **后端**：Python + Flask + NumPy
- **前端**：HTML + JavaScript + Plotly.js
- **数值方法**：有限差分法（迭代求解）

## 如何使用

### 方法一：使用Flask应用

1. 安装依赖：
   ```bash
   pip install flask numpy
   ```

2. 运行Flask服务器：
   ```bash
   python app.py
   ```

3. 打开浏览器访问：`http://localhost:5000`

4. 在界面上设置参数：
   - 板间距 (m)
   - 左板电压 (V)
   - 右板电压 (V)

5. 点击"求解并显示结果"按钮查看电势和电场分布

### 方法二：使用独立脚本

1. 安装依赖：
   ```bash
   pip install numpy matplotlib
   ```

2. 修改脚本中的参数（可选）：
   - `d`：板间距
   - `V1`：上板电压
   - `V2`：下板电压

3. 运行脚本：
   ```bash
   python laplace_solver.py
   ```

4. 结果将保存为 `laplace_result.png` 文件

## 算法说明

### 有限差分法

1. 初始化电势矩阵，设置边界条件（左右极板电压）
2. 迭代更新内部点的电势值：
   ```
   V[i,j] = 0.25 * (V[i,j-1] + V[i,j+1] + V[i-1,j] + V[i+1,j])
   ```
3. 检查收敛条件，当电势变化小于阈值时停止迭代

### 电场计算

使用梯度计算电场强度：
```
Ex, Ey = np.gradient(-V, dx, dy)
```

## 注意事项

- 本项目假设电容器为无限长，只考虑二维截面
- 计算精度和速度可通过调整网格密度（nx, ny）和迭代参数来平衡
- 对于复杂边界条件，可能需要修改边界处理逻辑
