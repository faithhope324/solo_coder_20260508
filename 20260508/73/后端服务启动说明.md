# 后端服务启动说明

## 问题现象

打开前端页面后，右上角显示红色感叹号 + "后端服务未连接"

## 原因分析

后端服务没有启动，或者启动失败。

## 解决方案

### 方法一：使用启动脚本（推荐）

1. 双击 `start_backend.bat` 启动后端服务
2. 看到 "Uvicorn running on http://0.0.0.0:8000" 表示启动成功
3. 刷新前端页面，红色感叹号会变成绿色的 "后端服务正常"

### 方法二：手动启动

打开命令行，执行以下命令：

```bash
cd d:\project\20260508\73\backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 方法三：如果Python依赖未安装

首次运行需要安装依赖：

```bash
cd d:\project\20260508\73\backend
pip install -r requirements.txt
```

## 验证服务是否启动成功

### 方法一：浏览器访问

打开浏览器访问：http://localhost:8000/api/health

正常响应：
```json
{"status":"ok","message":"Scene Text Recognition and Translation System is running"}
```

### 方法二：命令行测试

```bash
curl http://localhost:8000/api/health
```

或

```bash
python -c "import requests; print(requests.get('http://localhost:8000/api/health').json())"
```

## 常见问题

### 1. 端口被占用

如果8000端口被占用，可以修改启动命令中的端口号：

```bash
python -m uvicorn main:app --host 0.0.0.0 --port 8001 --reload
```

同时需要修改前端 `vite.config.ts` 中的代理端口。

### 2. 首次启动太慢

首次启动时，EasyOCR会自动下载模型文件（约200MB），请耐心等待。

看到以下日志表示模型下载中：
```
Downloading detection model, please wait...
Downloading recognition model, please wait...
```

### 3. Python版本问题

确保Python版本 >= 3.8，推荐使用 Python 3.10 或 3.11。

### 4. PaddleOCR不兼容

如果使用Python 3.12+，PaddleOCR可能不兼容。

**已修复**：项目已改用EasyOCR，兼容性更好。

## API接口列表

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/health` | GET | 健康检查 |
| `/api/languages` | GET | 获取支持的语言列表 |
| `/api/ocr` | POST | OCR文字检测 |
| `/api/translate` | POST | 文本翻译 |
| `/api/process` | POST | 完整处理流程 |
| `/api/download_annotated` | POST | 下载标注图片 |

## 技术支持

如仍有问题，请检查：
1. Python环境是否正确
2. 依赖包是否完整安装
3. 防火墙是否阻止了8000端口
4. 是否有其他程序占用8000端口
