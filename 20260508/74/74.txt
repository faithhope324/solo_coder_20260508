### 📖 使用流程

1. **创建几何模型**
   - 在工具栏选择绘图工具（矩形/圆形/多边形）
   - 在画布上点击绘制图形

2. **设置材料属性**
   - 选中绘制的图形
   - 在右侧「Geometry」面板选择材料或自定义参数
   - 勾选「Set as Electrode」设置为电极，并输入电势值

3. **配置求解器**
   - 切换到「Solver」标签页
   - 设置计算域尺寸和网格密度
   - 点击「Run Simulation」开始求解

4. **查看结果**
   - 切换到「Results」标签页
   - 查看电势、电场统计信息
   - 开关网格、等高线、矢量图显示
   - 调节等高线级数和矢量缩放

5. **导出报告**
   - 点击「Export PDF Report」生成并下载仿真报告

```python
def element_stiffness_matrix(p1, p2, p3, permittivity):
    dN_dx, dN_dy = shape_function_derivatives(p1, p2, p3)
    area = triangle_area(p1, p2, p3)
    epsilon = EPS0 * permittivity
    Ke = epsilon * area * (np.outer(dN_dx, dN_dx) + np.outer(dN_dy, dN_dy))
    return Ke
```

```typescript
export const colormapBlueWhiteRed = (value: number, min: number, max: number): string => {
  const t = Math.max(0, Math.min(1, (value - min) / (max - min)));
  if (t < 0.5) {
    // 蓝色 → 白色
    const r = Math.floor(2 * t * 255);
    const g = Math.floor(2 * t * 255);
    return `rgb(${r},${g},255)`;
  } else {
    // 白色 → 红色
    const b = Math.floor(2 * (1 - t) * 255);
    const g = Math.floor(2 * (1 - t) * 255);
    return `rgb(255,${g},${b})`;
  }
};
```
