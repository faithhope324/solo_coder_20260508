## 1. 产品概述

天气数值预报可视化系统是一个基于数值天气预报模型的专业气象数据可视化平台。系统后端运行简化版天气预报模型（含物理推理过程），生成网格化气象数据；前端基于 Leaflet 地图和 Canvas 叠加技术，实现温度、湿度等值线和风场流线的动态可视化，并支持时间步长滑块动态浏览预报演变过程。

- 目标用户：气象爱好者、科研人员、教学演示
- 核心价值：将复杂数值预报数据转化为直观可交互的地图可视化

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 浏览和交互所有可视化功能 |

### 2.2 功能模块

1. **主页面**：地图可视化区、变量控制面板、时间步长控制、高度层选择、经纬度查询

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 地图可视化区 | Leaflet 地图底图 + Canvas 叠加等值线/流线 |
| 主页面 | 变量控制面板 | 切换温度/湿度/风速变量，选择等值线或流线渲染模式 |
| 主页面 | 高度层选择 | 支持 1000hPa / 850hPa / 500hPa / 250hPa 等压面层 |
| 主页面 | 时间步长滑块 | 滑块控制预报时间步（0-72小时），动态刷新可视化 |
| 主页面 | 经纬度查询 | 输入经纬度坐标，获取该点的温度/湿度/风速数值 |
| 主页面 | 信息面板 | 显示当前选中点的详细气象数据 |

## 3. 核心流程

用户打开系统 → 地图加载默认区域（中国及周边） → 选择气象变量（温度/湿度/风速） → 选择高度层 → 拖动时间步长滑块 → 地图上绘制等值线或风场流线 → 点击地图查询某点数值 → 信息面板显示详细数据

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝（#0B1426）搭配青蓝渐变（#00D4FF → #0066FF），营造专业气象科技感
- 辅助色：暖橙（#FF6B35）用于高亮和警示
- 按钮风格：圆角半透明玻璃态按钮（glass-morphism）
- 字体：标题使用 Rajdhani（科技感），数据使用 JetBrains Mono（等宽数据字体）
- 布局风格：全屏地图 + 左侧浮动控制面板 + 底部时间轴
- 图标风格：线性描边图标（lucide-react）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 主页面 | 地图可视化区 | 全屏 Leaflet 地图，深色底图，Canvas 叠加层 |
| 主页面 | 控制面板 | 左侧浮动玻璃态面板，变量切换按钮组，高度层下拉框 |
| 主页面 | 时间轴 | 底部浮动滑块条，显示时间标签，拖拽手柄 |
| 主页面 | 信息面板 | 右下角浮动卡片，显示经纬度、温度、湿度、风速数值 |
| 主页面 | 图例 | 地图右下角色标条，对应当前变量色阶 |

### 4.3 响应式

- 桌面端优先设计，地图占满全屏
- 控制面板可折叠以适配小屏幕
- 时间轴始终固定在底部
